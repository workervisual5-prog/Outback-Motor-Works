# Outback Motor Works
`npm install` then `npm run dev` (build: `npm run build`).
- Business details, services, hours, reviews, gallery, email: `src/data/site.js`
- Colours: CSS variables in `src/index.css` (`:root`)
- Booking form: replace `sendBooking()` in `src/App.jsx` with EmailJS
- SEO: `index.html` (set the real domain in canonical, replace mock email)
- Images: `public/images`
